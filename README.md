# 📊 Admin Analytics Dashboard

### SPS Web Development Internship – September 2026

A responsive Admin Analytics Dashboard developed as part of **Task 3** of the SPS Web Development Internship.

The dashboard is built using **HTML, CSS, Bootstrap, jQuery, and Chart.js**. It includes responsive dashboard components, interactive navigation, summary statistics, charts and graphs, modals, notifications, and a recent activity section.

---

## 🌐 Live Demo

[View Live Dashboard](https://dashboard-fawn-theta-32.vercel.app/)

---

## 📌 Task Requirements

The task was to:

- Create a dashboard using Bootstrap
- Use jQuery for interactions
- Include charts and graphs

The project fulfills these requirements through a responsive admin dashboard with multiple interactive components and data visualizations.
